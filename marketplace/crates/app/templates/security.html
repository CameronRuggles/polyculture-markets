Two-factor authentication (TOTP)

Moderator accounts must enroll: every moderator action (resolving a dispute, reading disclosures, approving a seller, warning or closing an account, removing a listing) requires a current code. Sellers must enroll before they can set a payment identity. Enrolled accounts must also enter a code at every log in. Any account may enroll. Starting enrollment requires your current passphrase (step-up); a code is single-use — once accepted, the same code is refused everywhere until it expires.

Passphrase

Change your passphrase here — you do not need to spend your recovery code. Changing it signs out every OTHER session; this one stays signed in.

Recovery code

Issue a new recovery code. The new code replaces every previous one — old codes stop working immediately. The new code is shown once, on the account page, after you confirm your passphrase (plus a TOTP code if you are enrolled).

Close this account

Closing ends this identity: you will not be able to log in again, your listings will be unpublished, unused payment addresses retired, and your reputation will stop growing. Your order and review history stays visible to people you traded with — their records depend on it. Closure cannot be undone from here. It also does not erase anything, and nothing prevents a new account being registered later.
